# Cache And Output Inventory

Generated: 2026-06-20

This is a cleanup registry for large generated artifacts and path-dependent
caches. It is intentionally non-destructive: no large data files were moved or
deleted when this inventory was created.

## Rules

- Do not move a cache if code still defaults to that exact path unless a
  compatibility plan exists.
- Prefer cold-storage plus a pointer/README over deletion for scientific
  provenance.
- For source-tree caches, first update code defaults or add explicit CLI/env
  overrides, then move the cache under `outputs/cache/` or external storage.
- Keep active Figure 4 / BackImage production outputs in place until the final
  figure pack and provenance notes are written.
- Record checksum, cold-storage location, regeneration command, and last
  verification date before removing any local large artifact.

## 0. Phase 1 scientific objective

Phase 1 asks:

> Is the shared variability of foveal V1 during fixation partly the low-dimensional, image-conditioned derivative of the viewed image under self-generated retinal motion?

There are three linked analyses:

1. **2D FEM covariance geometry / derivative-code analysis**
2. **Noise-correlation reconciliation and reduction quantification**
3. **Aggregation-scaling diagnostic**

The current execution priority is:

1. Continue **2D covariance / derivative-geometry refinement** to sharpen mechanism-level interpretation.
2. Run **active-sensing E-optotype identity-phase checks** as the next substantive branch.
3. Draft Phase 1 closeout package once substantive branch outputs are integrated.

## 1. Phase 1 success criteria

### 1.1 Headline-worthy outcome

Phase 1 becomes a main manuscript anchor if:

1. FEM covariance is low-dimensional and plausibly translation-like.
2. Image-specific or model-predicted geometry explains more covariance than global/shared or shuffled controls.
3. FEM correction substantially reduces conventional positive noise correlations and/or reveals weak negative residual correlations.
4. The signal becomes more reliable with aggregation, explaining the per-window trajectory null.

### 1.2 Supporting outcome

Phase 1 still supports the manuscript if:

1. FEM covariance is low-dimensional but mostly shared rather than strongly image-specific.
2. Noise correlations are reduced but do not flip sign.
3. Aggregation improves reliability but effect sizes remain modest.

Then the claim becomes:

> FEMs explain a measurable low-dimensional component of V1 shared variability, but the strongest derivative-code/decorrelation interpretation is not fully supported.

### 1.3 Null outcome

Phase 1 does not support the high-impact claim if:

1. Covariance dimensionality is not low or not eye-linked.
2. Model or image-specific geometry does not outperform controls.
3. Noise-correlation reduction is small or explained by estimator artifacts.
4. Aggregation-scaling does not improve reliability.

Then manuscript framing should fall back to the existing partial bridge and model-side mechanism.

# 5. Primary FEM covariance estimator

Phase 1 will use one primary estimator and one sensitivity estimator.

## 5.1 Primary estimator: McFarland-style trajectory-similarity covariance

Use the McFarland-style estimator as the primary empirical FEM covariance object, because it is closest to the existing preliminary FEM_V1_Fovea results and to the noise-correlation analysis.

Conceptually:

1. group repeated image/time windows,
2. compute pairwise eye-trajectory or eye-position similarity,
3. estimate neural covariance as a function of trajectory similarity,
4. recover the eye-linked covariance/intercept/slope structure.

The implementation should use the existing covariance pipeline if available.

Output object:

```text
C_FEM_mcfarland[unit, unit]
```

and/or low-dimensional empirical geometry object:

```text
B_emp_mcfarland
```

depending on existing pipeline outputs.

## 5.2 Sensitivity estimator: B_emp regression covariance

Fit:

```text
R_resid = B_emp * [eye_x, eye_y] + error
```

Then compute:

```text
R_eye_pred = eye @ B_emp.T
C_eye_emp = covariance(R_eye_pred)
```

This is closer to the prior empirical bridge and should be reported as a sensitivity check.

## 5.3 Required comparison

Every session summary must report both if available:

```text
primary_C_FEM_method = "mcfarland"
sensitivity_C_FEM_method = "B_emp_regression"
primary_vs_sensitivity_alignment
primary_vs_sensitivity_cov_corr
```

If the two estimators disagree strongly, the readme must flag this as a major interpretation issue.

# 6. Analysis 1: 2D FEM covariance geometry / derivative-code analysis

## 6.1 Core question

Does FEM-induced covariance behave like a low-dimensional, image-conditioned transformation object rather than a global eye-position signal?

---

## 6.2 Shared vs image-specific models

Compare at least four geometry models.

### Model 1: global shared eye basis

```text
R_resid = B_shared * eye + error
```

### Model 2: image-specific basis

```text
R_resid = B_image[image] * eye + error
```

Use only image/window contexts with enough samples.

### Model 3: shared plus image-specific residual

```text
R_resid = B_shared * eye + B_delta[image] * eye + error
```

### Model 4: model-predicted basis

Project empirical covariance into model-predicted bases:

```text
B_model
FEM_PCs
model_FEM_covariance eigenspace
```

---

## 6.3 Dimensionality metrics

For each covariance object compute:

```text
total_variance
top1_variance_fraction
top2_variance_fraction
top5_variance_fraction
participation_ratio
effective_dimensionality
eigenvalue_spectrum
```

Participation ratio:

```text
PR = (sum eigenvalues)^2 / sum(eigenvalues^2)
```

## 6.4 Interpretation of participation ratio

Do not force a 2D interpretation.

### PR near 2

Supports a 2D translation-like covariance.

### PR between 3 and 5

Not a null. Interpret as a richer eye-linked signal that may include:

- lagged eye position/history,
- velocity or acceleration components,
- image-conditioned gain modulation,
- secondary translation axes,
- residual nonretinal eye-linked signals.

If PR > 2.5 but model/FEM alignment remains above controls, the framing should shift from:

> 2D translation code

to:

> low-dimensional eye-linked code with translation as a dominant component.

### PR high and no model alignment

Weakens the derivative-code story.

---

## 6.5 Alignment metrics

### A. Subspace overlap

```text
overlap = trace(U_emp.T @ U_model @ U_model.T @ U_emp) / k
```

Use k = 2 and k = 5.

### B. Covariance correlation

```text
corr(vec(C_emp), vec(C_model))
```

Use upper triangle or Frobenius-normalized similarity.

### C. Projection fraction

```text
frac = trace(U_model.T @ C_emp @ U_model) / trace(C_emp)
```

### D. Reliability-normalized alignment

```text
alignment_norm = (alignment_model - alignment_shuffle) / reliability_ceiling
```

### Reliability gate

If:

```text
reliability_ceiling < 0.20
```

then:

```text
alignment_norm = NaN
alignment_norm_status = "low_reliability_ceiling"
```

Do not report inflated ceiling-normalized values from near-zero denominators.

# 7. Analysis 2: noise-correlation reconciliation / reduction quantification

## 7.1 Core question

Are conventional positive V1 noise correlations partly reafferent covariance induced by FEMs, and how much positive shared variability is removed by matched FEM correction?

---

## 7.2 Definitions

For each session and unit pair, compute noise correlations under multiple correction levels.

### A. Raw noise correlation

Correlation of trial-to-trial activity after minimal preprocessing.

### B. PSTH-corrected noise correlation

```text
R_psth_resid = R - mean_R(image, time)
```

### C. Eye/FEM-corrected residual correlation

```text
R_eye_corrected = R_psth_resid - R_eye_pred
```

where `R_eye_pred` comes from the primary FEM covariance/eye model.

### D. Model-predicted reafferent covariance

Compute noise-correlation-like covariance from predicted retinal-reafference component.

### E. Final residual

Residual after removing stimulus/time and eye-predicted/reafferent components.

---

## 7.5 Synthetic controls: concrete data-generating processes

All synthetic controls should match empirical session dimensions when possible:

```text
n_trials = empirical n_trials
n_time_bins = empirical n_time_bins
n_units = empirical n_primary_units
eye traces = empirical eye traces
image/time labels = empirical labels
valid mask = empirical valid mask
```

Use empirical mean rates per unit as the default rate distribution.

### Control 1: independent Poisson + known eye component

Purpose: test whether the pipeline creates negative residual correlations from independent noise.

Generate:

```text
lambda_i(t,k) = base_rate_i(t,k) + g * eye_component_i(t,k)
spikes_i(t,k) ~ Poisson(max(lambda_i, epsilon))
```

where:

- `base_rate_i(t,k)` is empirical PSTH or smoothed mean rate,
- `eye_component = eye @ B_synth.T`,
- `B_synth` can be sampled from empirical `B_emp` after normalization,
- `g` chosen to match empirical FEM variance fraction.

Ground truth intrinsic correlation:

```text
0
```

Expected residual after correction:

```text
near 0, not negative
```

### Control 2: positive intrinsic Gaussian/Poisson latent covariance + eye component

Purpose: test whether positive intrinsic correlations are preserved after correction.

Generate latent shared noise:

```text
z[t] ~ Normal(0, 1)
intrinsic_i[t] = a_i * z[t] + independent_noise_i[t]
```

Then:

```text
lambda_i = base_rate_i + eye_component_i + intrinsic_i
```

Convert to spikes with Poisson or rectified Gaussian approximation.

Set ground-truth median intrinsic correlation to a known value, e.g.:

```text
+0.03 to +0.05
```

Expected residual:

```text
recovers positive intrinsic correlation
```

### Control 3: zero intrinsic covariance + estimated eye component

Purpose: test overfitting bias from estimating `B_emp`.

Generate with independent noise and known eye component, but fit `B_emp` from the synthetic data rather than using the true `B_synth`.

Expected residual:

```text
near 0
```

If negative, the estimator can induce anticorrelation.

### Control 4: shuffled-eye correction

Purpose: test whether correction with incorrect eye traces can create apparent false reductions or sign artifacts.

Apply eye correction using permuted eye traces.

Expected result:

```text
little reduction and no structured sign artifact
```

### Control 5: cross-validated correction

Purpose: test whether fitting and subtracting on the same samples causes anticorrelation.

Fit eye component on split A and subtract/predict on split B, then reverse.

Expected result:

```text
true reduction should survive cross-validation without inducing negative-bias artifacts
```

# 8. Analysis 3: aggregation-scaling diagnostic

## 8.1 Core question

Does empirical eye-linked geometry become reliable only through aggregation?

This analysis explains the coexistence of:

- successful covariance/bridge analyses,
- failed Stage 3/4 single-window trajectory prediction.

---

## 8.2 Objects to scale

Run aggregation scaling on at least one, preferably both:

### A. \(B_{\text{emp}}\) reliability

For different numbers of trials/windows, estimate `B_emp` and compute split-half reliability or similarity to full-data estimate.

### B. FEM covariance reliability

For different numbers of windows/trial pairs, estimate eye-linked covariance and compare split halves.

---

## 8.3 Sampling plan

For each session:

```text
N_windows = [5, 10, 20, 40, 80, 160, max_available]
```

Adjust to available data.

For each N:

1. sample N windows/repeats without replacement,
2. split into halves,
3. estimate geometry independently,
4. compute similarity/reliability,
5. repeat bootstrap 100-500 times.

Use random seed control.

---


Fit simple scaling curves if useful:


# 13. Engineering notes

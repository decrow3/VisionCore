A General Info Framework for FEM Function in Free Viewing
Core idea (I_z(\tau))

The cleanest way to unify the Vernier, natural-image, and free-viewing analyses is to define a general objective:

[
U(\tau) = I_z(\tau)
]

where:

(\tau) is the retinal trajectory generated by the eye movement,
(z) is the visual variable the observer needs to know,
(I_z(\tau)) is the information about (z) available in the V1 population response under trajectory (\tau).

In words:

Good eye movements are those that make V1 activity informative about the relevant visual latent (z).

This avoids vague objectives such as “high activity,” “refresh,” or “generic stability.” It also avoids treating whitening as the sole objective. Whitening, decorrelation, pose cost, and motor cost can all be interpreted as constraints or companion terms, but the central question is what V1 activity tells an observer about (z).

The Vernier task is the clean special case:

[
z = \delta
]

where (\delta) is the Vernier offset. The Vernier Fisher analysis already estimates (I_z(\tau)) in the scalar small-offset case.

The free-viewing problem is harder because (z) is not explicitly labeled. The goal of this roadmap is to define plausible, literature-supported candidates for (z), then ask whether real FEM statistics look useful under those objectives.

Why this reframing is needed

Several analyses have now ruled out simpler explanations.

Real FEMs are not uniquely optimal.
Real traces often match phase-cloud or random controls. Exact temporal order is not the main object.
Raw input whitening is incomplete.
Biological drift whitens natural-image input relative to stabilization, but unconstrained whitening favors larger-than-biological motion.
V1 temporal weighting does not rescue whitening.
Weighting retinal spectra by the fitted twin’s temporal sensitivity still does not recover biological drift scale for most metrics.
Vernier favors reduced motion.
Fine-position information in the V1 twin is strongest at sub-biological motion scales, roughly (D=0.125) to (0.25), and only helps substantially when pose is known.
Compactness alone does not solve pose ambiguity.
Compact-aware pose-blind projections do not recover the pose-aware Vernier benefit.
Local scalar image features do not predict FEM magnitude well.
BackImage local contrast, high-frequency power, and related scalar features do not robustly predict speed, RMS radius, or diffusion after controls.
Raw local edge geometry predicts drift axis better than current twin objectives.
Drift axes are modestly aligned with local edge geometry, but the current PA/PB/Pareto fixed-grid twin objectives do not improve over raw edge.

These results do not undermine the active-sensing idea. They tell us that the right objective is more specific:

FEMs should be evaluated by the information they provide about a relevant latent visual variable, under explicit observer assumptions and costs.

General formulation

Let the digital twin define a deterministic mapping:

[
r_\tau = F_\theta(I,\tau)
]

where (I) is the image or local patch and (r_\tau) is the V1 population response sequence generated by trajectory (\tau).

Let:

[
z = g(I)
]

be a latent description of the visual input.

Then define:

[
U(\tau) = I(z; r_\tau)
]

or, under a linear-Gaussian approximation:

\frac{1}{2}
\log \det
\left(
I + C_z B_\tau^\top \Sigma^{-1} B_\tau
\right)
]

where:

(C_z) is the prior covariance or weighting of the latent variables,
(B_\tau) is the sensitivity of the response to (z),
(\Sigma) is the assumed observation covariance.

For scalar (z), this reduces to Fisher information:

[
U(\tau) = J_z^\top \Sigma^{-1}J_z
]

This is exactly the logic used in the Vernier analysis.

Observer variants

The framework should always distinguish pose-aware and pose-blind observers.

Pose-aware objective

[
U_{\mathrm{PA}}(\tau) = I(z; r_\tau \mid \tau)
]

The observer knows the retinal phase or trajectory, so it can interpret each response in the correct local chart.

This asks:

If pose is known, does this trajectory make V1 more informative about (z)?

Pose-blind objective

[
U_{\mathrm{PB}}(\tau) = I(z; r_\tau)
]

The observer does not know retinal phase. Motion-induced response variation becomes part of the effective covariance.

This asks:

If pose is hidden, does this trajectory still help, or does it create nuisance covariance?

Pose uncertainty objective

Biology is probably between these extremes. We should also allow:

[
U_{\sigma_{\mathrm{pose}}}(\tau)
]

where retinal pose is known with Gaussian uncertainty.

This asks:

How precise must pose knowledge be for the active-sampling benefit to survive?

Pose gap

The key coordinate-frame quantity is:

U_{\mathrm{PA}}(\tau)

U_{\mathrm{PB}}(\tau)
]

This is the generalized version of the pose-aware minus pose-blind Fisher gap.

Candidate choices for (z)

The main uncertainty in free viewing is not the mathematical form of the objective. It is the choice of (z).

We should treat each (z) as a hypothesis about what local information the animal may be sampling during free viewing.

(z_1): local spatial position or phase

This is closest to the existing spatial-information and Vernier work.

Examples:

local image displacement,
local phase,
fine spatial position,
edge offset.

Use when the task is about where image structure is located.

Special case:

[
z=\delta
]

for Vernier offset.

Interpretation:

FEMs help if they make V1 more informative about fine spatial position.

(z_2): external low-level feature coefficients

Define (z) using a fixed image-feature basis:

Gabor coefficients,
DCT coefficients,
spatial-frequency band energies,
local phase coefficients,
oriented filter responses,
texture coefficients.

This is attractive because it is not self-referential to the twin.

Interpretation:

FEMs help if they make V1 responses more informative about low-level local image structure.

(z_3): salience or priority features

Define (z) as local features known to contribute to fixation priority:

local contrast,
orientation contrast,
high-spatial-frequency power,
edge density,
local feature surprise,
saliency-map coefficients.

This connects to the free-viewing and fixation-prediction literature.

Interpretation:

FEMs help if they improve V1 information about the visual features that make the fixated region worth sampling.

(z_4): feature surprise

Define:

[
z = -\log p(\phi(I))
]

where (\phi(I)) is a feature vector and (p(\phi)) is its distribution across natural images.

This treats informative locations as statistically unexpected or distinctive.

Interpretation:

FEMs help if they improve V1 information about locally surprising features.

(z_5): twin-internal feature representation

Define:

[
z = h_{\mathrm{core}}(I)
]

where (h_{\mathrm{core}}) is an internal feature representation from the model core or ConvGRU.

This is powerful but more self-referential.

Interpretation:

FEMs help if they make the output population informative about the twin’s own internal visual feature representation.

This should be treated as a model-internal objective, not an independent biological target.

Costs and constraints

The core objective is (I_z(\tau)), but several costs should be measured alongside it.

Pose cost

Motion can create pose-dependent covariance that hurts pose-blind observers.

U_{\mathrm{PA}}(\tau) - U_{\mathrm{PB}}(\tau)
]

or an explicit covariance burden:

\operatorname{tr}\left(\operatorname{Cov}\tau[r\tau]\right)
]

Motor cost

Use trajectory statistics such as:

RMS displacement,
path length,
velocity,
acceleration,
fixation-window violation probability.
Whitening or decorrelation

Use as a companion term, not the scale-setting objective:

spectral flatness,
spectral entropy,
feature covariance entropy,
V1 response covariance entropy.
Representation cost

Measure whether motion destroys or destabilizes information about (z):

[
\Delta U_z = U_z(\tau) - U_z(\mathrm{static})
]

and compare pose-aware and pose-blind forms.

Planned analysis sequence
Stage 1: Recast Vernier as the scalar (I_z) proof of concept

Goal:

Show that the existing Vernier result is the scalar special case of the general (I_z(\tau)) framework.

Use:

[
z=\delta
]

Metrics:

pose-aware Fisher,
pose-blind Fisher,
pose-uncertainty sweep,
compact-aware control,
scale sweep.

Interpretation:

The framework works cleanly when (z) is explicit. Reduced phase sampling improves pose-aware information about fine position, but pose-blind readout is strongly penalized.

This becomes the pedagogical entry point.

Stage 2: Define external feature (z) for BackImage patches

Goal:

Build a non-self-referential local feature latent for free-viewing patches.

Candidate features:

oriented Gabor or steerable-pyramid coefficients,
DCT coefficients in local spatial-frequency bands,
local phase and orientation energy,
contrast and high-SF power,
saliency or priority-map coefficients.

For each BackImage fixation patch, store:

[
z_i = \phi(I_i)
]

Then define candidate micro-movements and run the twin to obtain (r_\tau).

Primary candidate motions:

real drift axis,
raw edge axis,
edge-orthogonal axis,
spectrum axis,
random axes,
fixed-grid axes,
scaled motion variants.
Stage 3: Compute (I_z(\tau)) under pose-aware and pose-blind observers

For each patch and candidate motion:

[
U_{\mathrm{PA}}(\tau)=I(z;r_\tau\mid\tau)
]

[
U_{\mathrm{PB}}(\tau)=I(z;r_\tau)
]

Use simple estimators first:

Linear ridge decoding of (z) from (r_\tau).
Cross-validated (R^2) or explained variance.
Linear-Gaussian information approximation.
Fisher trace if using local perturbations of (z).

Primary outputs:

(U_{\mathrm{PA}}),
(U_{\mathrm{PB}}),
pose gap,
per-spike normalization,
motion-scale dependence,
axis dependence.
Stage 4: Ask whether real drift axes improve (I_z)

Primary comparisons:

[
U_z(\mathrm{real\ drift\ axis})
\quad \text{vs} \quad
U_z(\mathrm{random\ axis})
]

[
U_z(\mathrm{real\ drift\ axis})
\quad \text{vs} \quad
U_z(\mathrm{edge\ axis})
]

[
U_z(\mathrm{edge\ axis})
\quad \text{vs} \quad
U_z(\mathrm{edge\ orthogonal})
]

The important criterion is not simply whether edge wins. Raw edge is already the baseline.

The model earns explanatory value if (I_z):

predicts which fixations show strong drift alignment,
predicts deviations from raw edge,
predicts drift anisotropy,
predicts motion scale,
or beats raw edge in held-out sessions.
Stage 5: Compare (z) candidates

Run the same analysis for multiple (z) definitions.

Candidate ranking criteria:

Does the objective prefer biologically observed drift axes?
Does it beat raw edge?
Does it predict alignment strength?
Does it generalize across sessions?
Does it produce sensible pose-aware versus pose-blind behavior?
Does it avoid trivial high-rate or high-motion solutions?

Possible outcomes:

Low-level Gabor (z) works best.
Salience/priority (z) works best.
Twin-core (z) works best.
No (z) beats raw edge.

Each outcome is interpretable.

Current BackImage update:

The corrected low-level Gabor/pyramid branch is still alive, but the decisive
question has become scale-dependent. The original n=64 pathfinder at 0.125x
observed RMS showed Gabor pose-blind delta responses favoring the real drift
axis over random and edge axes. The apparent larger Gabor-only n=128 check was
not a clean post-fix replication because it used the older 4x4 feature
dimensionality and absolute observers.

A clean n=128 canonical replication has now been run with the fixed feature
shapes, the canonical 756-unit twin, rand8, and `pose_blind_delta_mean`:

`backimage_latent_information_cleanrep_n128_rel0125-05_rand8_delta`

At the primary Gabor `k=4`, 0.125x scale, real drift beat random directionally
(`+3.31`, CI `[-0.14, +8.57]`, p<=0 `0.0396`) but did not beat edge
(`-0.36`, CI `[-2.25, +1.09]`). At larger relative scales, several real-vs-edge
effects became strong, including Gabor `k=4` at 0.5x and pyramid `k=4/k=8` at
0.5x/0.25x. This means the branch should no longer be framed as a
small-scale-only screen. The key ecological question is whether the
local-feature `I_z` advantage becomes most animal-relevant near `1x` observed
RMS, or whether random axes rise similarly with scale.

The stronger current result is local preservation rather than information
maximization: edge-parallel small displacements disrupt pixels and multiple
signed V1-twin response metrics less than edge-orthogonal displacements, and
pixel/twin signed stability advantages are positively correlated across
windows. Thus the BackImage story should currently be framed as constrained
local-structure preservation, not global feature-information maximization.

The next `I_z` run should be a locked scale curve, not a broad pathfinder:
canonical 756 units, `pose_blind_delta_mean`, fixed Gabor/pyramid local fields,
real/random/raw-edge/edge-orthogonal axes, and scales 0.125x, 0.25x, 0.5x, 1x,
and 2x observed RMS. The figure-relevant outcome is real-specific support near
1x (`real > random` and `real > edge`) or, more weakly, an edge-structured
result (`real ~= edge > random`).

Stage 6: Only then consider optimized or adversarial trajectories

Full trajectory optimization should come after a viable (z) is identified.

For a chosen (z), define:

[
\tau^* = \arg\max_\tau U_z(\tau) - C(\tau)
]

and:

[
\tau^- = \arg\min_\tau U_z(\tau) + C(\tau)
]

Run these only if the axis-grid analysis shows that (I_z) captures biologically relevant structure.

Interpretation:

If optimized (>) real (>) random (>) adversarial, the objective has biological relevance.
If optimized does not beat raw edge or does not predict real geometry, stop.
If adversarial is not worse than random, the objective is not constraining the problem.
Required controls
Raw image geometry baselines

Always include:

raw edge axis,
gradient axis,
spectrum axis,
random axis,
session-shuffled patch-axis controls.

Raw edge is now the benchmark any model objective must beat.

Observer controls

Always include:

pose-aware,
pose-blind,
pose uncertainty,
per-spike normalization.
Motion controls

Include:

real drift axis,
order-shuffled motion if relevant,
matched amplitude controls,
scale sweeps.
Population-space controls

When testing compact geometry or covariance-aware objectives, use:

full canonical population if possible,
or repeated large population samples,
not only the 16-channel matched center space.

The 16-channel space is useful for continuity with Figure 5 and recorded-session comparability, but may be underpowered for population-geometry claims.

Statistical controls

Use:

session-level summaries,
sign counts across sessions,
within-session patch shuffles,
held-out session evaluation,
reliable-axis subsets,
raw-edge baseline comparison.
Decision table
Strong positive

Criteria:

A specific (z) objective predicts real drift geometry better than raw edge.
The effect survives within-session shuffles and held-out sessions.
Pose-aware and pose-blind variants behave sensibly.
The objective also predicts anisotropy or scale, not only axis.

Interpretation:

FEMs during free viewing appear to support V1 information about a specific local visual latent.

Moderate positive

Criteria:

The (z) objective does not beat raw edge, but predicts where edge alignment is strong or predicts drift anisotropy.

Interpretation:

The local image-geometry effect is real, and the model captures part of when it matters.

Useful negative

Criteria:

No (z) objective beats raw edge or predicts alignment strength.

Interpretation:

Raw image geometry remains the best description of the drift-axis effect. The V1 twin does not yet provide a mechanistic objective for free-viewing FEMs.

Pose-only result

Criteria:

(I_z) is high under pose-aware readout but collapses under pose-blind readout.

Interpretation:

The feature information is present in phase-dependent responses, but requires pose information to be useful.

This would align with Vernier and covariance-aware results.

Overfit or artifact

Criteria:

Objective prefers maximal motion or high firing rate.
Results disappear after per-spike normalization.
Results depend on one (z), one session, or one preprocessing choice.
Objective does not beat raw edge or shuffled controls.

Interpretation:

Do not promote.

Manuscript-facing synthesis if successful

If a (z) objective works, the result could be described as:

The same information-theoretic framework that explains the Vernier result can be extended to natural viewing by replacing the task variable with local visual features. In this formulation, FEMs are evaluated by how much they improve V1 information about the currently fixated image features, under explicit pose-aware and pose-blind observer assumptions. This approach predicts that the value of retinal motion depends on both the local image feature latent and the observer’s access to retinal pose.

If no (z) objective works, the honest result is still useful:

The Vernier task shows that (I_z(\tau)) is a useful framework when the latent variable is known. In free viewing, however, the relevant latent remains uncertain. Current local feature and twin-derived objectives do not yet explain drift geometry beyond raw image edge structure.

Core claim boundary

This roadmap should not claim that free-viewing FEMs are optimal.

The strongest possible claim is:

FEMs can be evaluated as actions that shape the information available in V1 about a latent visual variable (z). Vernier provides the clearest scalar case. For free viewing, the open problem is to identify the relevant (z), with local feature, salience, and priority representations as the most defensible candidates.

This is the most general and least overcommitted formulation of the active-sensing program.

# Declan Archive

This folder holds historical planning notes, superseded handoffs, and closed
research branches that should remain available for provenance but should not be
the default reading path for current coding agents.

Use `declan/MANIFEST.md`, `declan/ANALYSIS_NARRATIVE.md`, current package
READMEs, and `AGENT_CONTEXT.md` for active navigation. Files here are retained
as historical guardrails.

Archive conventions:

- `Status`: why the file is no longer a default entrypoint.
- `Superseded by`: the current document, package, or branch to consult first.
- `Still useful for`: what historical context the file preserves.
- `Do not use for`: claims or commands the archived file should not drive.

# Forward Twin Reafferent Denoising Analysis

## Motivation

The law-of-total-covariance analysis already shows that conditioning on eye position removes a component of recorded V1 shared variability. The covariance-geometry analysis already shows that the digital twin's retinal-translation geometry predicts part of the recorded FEM covariance. Therefore, a new "denoising" analysis is only valuable if it adds something beyond:

> eye-linked variance can be removed.

The useful new claim is single-trial and out-of-sample:

> A forward prediction from the digital twin, computed only from the image and measured eye trace, predicts the specific reafferent fluctuation in recorded V1 responses on held-out trials.

This is different from estimating `Sigma_FEM` directly from recorded spikes. The correction is not fit to the recorded noise. It is generated by the model:

```text
Delta r_twin = twin(image, real eye trace) - twin(image, stabilized eye trace).
```

If this forward-predicted fluctuation reduces held-out recorded residual variance and noise correlations beyond matched controls, it would be a hard consequence of the translation-geometry account.

## Core Concept

For each trial or stimulus-history segment, decompose the recorded response as

```text
r_recorded = PSTH + Delta r_reafferent + epsilon.
```

The standard residual is

```text
e_classical = r_recorded - PSTH.
```

The forward twin predicts a reafferent fluctuation:

```text
Delta r_twin = r_twin(real FEM trace) - r_twin(stabilized trace).
```

The denoised residual is

```text
e_clean = r_recorded - PSTH - M Delta r_twin,
```

where `M` maps twin units into recorded units or into a matched recorded/twin unit space. The crucial requirement is that `M` must be estimated without using the held-out trial residuals being denoised.

The strongest compact-geometry version restricts the model-predicted fluctuation to the compact translation subspace:

```text
Delta r_compact = P_trans Delta r_twin
```

and then uses

```text
e_clean = r_recorded - PSTH - M Delta r_compact.
```

This is the single-trial analog of the covariance-capture result.

## Analysis Ladder

Run a ladder for validation, but do not necessarily present every rung in the main figure.

### Version 1: Recorded Regression Into Translation Subspace

Fit a model of the form

```text
e_classical ~= U_trans beta eye_features
```

using recorded residuals.

This is useful as an internal sanity check but should not be load-bearing.

Limitations:

- It fits the eye-to-residual map directly on recorded data.
- It is close to re-estimating the law-of-total-covariance result.
- Flexible eye regressors can reintroduce global gain or stimulus-PC contamination.

Interpretation:

> Internal diagnostic only unless carefully cross-fit and controlled.

### Version 2: Full Forward Twin Correction

Compute

```text
Delta r_twin = twin(image, real trace) - twin(image, stabilized trace)
```

and use it to correct recorded residuals.

This is valuable because the correction is determined by the image and eye trace, not by fitting recorded noise.

Question:

> Does the forward twin predict single-trial recorded reafferent fluctuations?

### Version 3: Compact Forward Twin Correction

Restrict the twin prediction to the compact translation geometry:

```text
Delta r_compact = P_trans Delta r_twin.
```

Question:

> Does the cross-fit compact translation subspace retain the single-trial denoising effect?

This is the most directly relevant version for the geometry claim.

## What Not To Use As The Headline

Do not use the bare statement:

```text
Var(e_clean) < Var(e_classical)
```

as the main claim.

That is too easy to obtain and too close to previous analyses. Any predictor correlated with the residual can reduce held-out variance somewhat. The relevant quantity is controlled excess denoising:

```text
denoising_gain_compact - denoising_gain_control.
```

The scientific question is not "can any eye-linked predictor reduce variance?" but:

> Does the retinal-translation prediction reduce residual variability more than gain-only, shuffled-eye, or random-subspace controls?

## Matched Controls

At minimum, include the following controls.

### 1. Shuffled-Eye-Trace Control

Compute a twin correction using mismatched or shuffled eye traces.

Purpose:

> Tests whether the correction requires the actual trial's eye trajectory.

Expected:

```text
real trace correction > shuffled trace correction
```

### 2. Random k-Dimensional Subspace Control

Restrict `Delta r_twin` to a random `k`-dimensional subspace matched to the compact basis dimension.

Purpose:

> Tests whether the compact translation geometry matters, or whether any low-dimensional correction works.

Expected:

```text
compact translation correction > random k-dimensional correction
```

### 3. Unit-Shuffled Translation Control

Use unit-shuffled tangent subspaces that preserve single-unit magnitudes but disrupt coordinated population geometry.

Purpose:

> Tests whether coordinated translation geometry is required.

Expected:

```text
compact translation correction > unit-shuffled translation correction
```

### 4. Gain-Only Control

Reduce the twin correction to its rank-1 global-rate or baseline-rate component.

Examples:

```text
Delta r_gain = projection of Delta r_twin onto r0
```

or

```text
Delta r_gain = population mean / global-rate component only.
```

Purpose:

> Tests whether the denoising is merely removing a gain mode.

Expected headline:

```text
compact translation correction - gain-only correction > 0
```

especially after removing global-rate and target-PC1 components.

## Primary Metrics

Compute metrics on held-out trials/images/sessions.

### Residual Variance Reduction

```text
VR = 1 - Var(e_clean) / Var(e_classical)
```

Report controlled excess:

```text
VR_compact - VR_gain
VR_compact - VR_shuffle
VR_compact - VR_random
```

### Noise Correlation Reduction

Compute mean off-diagonal noise correlation before and after correction:

```text
Delta noise corr = mean_corr(e_classical) - mean_corr(e_clean).
```

Report excess over controls.

### FEM-Covariance-Subspace Reduction

If `U_FEM` is available from the recorded covariance decomposition, measure residual variance specifically in the recorded FEM subspace:

```text
tr(U_FEM U_FEM^T Cov(e_clean)) / tr(U_FEM U_FEM^T Cov(e_classical)).
```

This asks whether the correction removes the component it is supposed to remove.

### Pairwise Covariance Pattern Improvement

Compare covariance matrices before and after correction:

```text
Cov(e_clean)
```

should have reduced similarity to the recorded `Sigma_FEM` pattern relative to controls.

## Cross-Validation And Leakage Guardrails

### No Recorded-Noise Fitting On Test Trials

The core correction must be generated from:

- the image,
- the measured eye trace,
- the trained digital twin,
- a twin-to-recorded mapping fit outside the held-out residuals.

Do not fit the correction directly to the test residuals.

### Unit Matching

`Delta r_twin` lives in twin units. Recorded residuals live in recorded unit space. The mapping must be handled carefully.

Options:

1. Use the matched recorded/twin unit space from the covariance-capture analysis.
2. Fit a twin-to-recorded linear mapping on training data only.
3. Report analyses in a shared canonical unit space if already validated.

Avoid leakage:

- Do not choose the mapping to maximize denoising on test residuals.
- Do not use the held-out covariance pattern to fit the map.

### Cross-Fit Compact Basis

For the compact correction:

- construct `P_trans` from image-disjoint twin tangents,
- apply to held-out images/trials,
- keep the same cross-fit discipline used for the compact geometry panels.

### Pre-Commit Interpretation

This analysis should be interpreted as a companion to the covariance-capture result, not as a load-bearing replacement.

If strong:

> It strengthens the model-derived reafference account by showing single-trial predictive power.

If weak:

> It bounds the account: the geometry may capture second-moment structure without predicting single-trial phase precisely.

A weak result should not reopen the covariance geometry claim.

## Success Criteria

### Strong Success

```text
compact forward correction reduces held-out residual variance
compact correction reduces noise correlations
compact correction exceeds shuffled-eye, random-subspace, unit-shuffle, and gain-only controls
effect persists after global-rate and target-PC1 removal
```

Interpretation:

> The digital twin predicts the specific single-trial reafferent fluctuation in recorded V1, and the compact translation geometry retains the effect.

### Partial Success

```text
full Delta r_twin correction works
compact P_trans Delta r_twin is weaker
```

Interpretation:

> The twin predicts reafferent single-trial fluctuations, but the k=10 compact first-order geometry is incomplete at the trial level.

### Covariance-Only Success

```text
covariance capture works
single-trial correction weak
```

Interpretation:

> The model captures the second-moment geometry of FEM-linked variability but not the precise trial-wise response phase. This is plausible and bounds the claim.

### Negative Result

```text
compact correction ~= controls
full correction ~= controls
```

Interpretation:

> The forward model does not predict trial-wise recorded residuals under the current mapping and data quality. This may reflect twin mismatch, unit-mapping limits, spike noise, or insufficient repeated-trial power.

## Why This Adds Value Beyond Existing Analyses

Existing analyses:

- identify `Sigma_FEM` from recorded data,
- show that eye-position conditioning reduces shared variability,
- show that model-derived translation geometry predicts recorded FEM covariance.

This analysis would add:

> a zero-free-parameter, forward, single-trial prediction of the reafferent fluctuation.

The key novelty is convergence between two independent corrections:

1. A data-derived correction estimated from recorded spikes via the covariance decomposition.
2. A model-derived correction computed from image content and measured eye trace without fitting recorded noise.

If both reduce the same residual variability and noise correlations, the case for retinal-translation reafference becomes much stronger.

## Recommended Figure/Reporting Strategy

Do not make this a large new main figure unless the controlled result is very strong.

Recommended reporting:

- companion panel or supplement to the covariance-capture analysis,
- show controlled excess denoising only,
- include gain-only and shuffled-eye controls in the main plot,
- put full ladder and sanity checks in supplement.

Possible compact plot:

```text
y-axis: excess held-out residual variance reduction
bars:
  compact forward twin correction
  gain-only control
  shuffled-eye control
  random-subspace control
```

or

```text
y-axis: residual noise correlation after correction
conditions:
  uncorrected
  recorded Sigma_FEM correction
  forward twin correction
  compact forward twin correction
  controls
```

## Suggested Text If It Works

```text
The model-derived translation geometry also made a single-trial prediction. For each held-out trial, we used the digital twin to compute the response change expected from the measured eye trace relative to a stabilized trace, without fitting the recorded residuals. Subtracting this forward-predicted reafferent fluctuation reduced held-out residual variance and noise correlations beyond shuffled-eye, random-subspace, and gain-only controls. The effect was retained when the twin prediction was restricted to the cross-fit compact translation subspace. Thus, the same compact geometry that captures FEM covariance also predicts a component of trial-wise reafferent variability in recorded V1.
```

## Suggested Text If Single-Trial Denoising Is Weak

```text
The forward twin correction did not substantially reduce held-out single-trial residuals beyond matched controls. This suggests that the compact translation geometry captures the second-moment structure of FEM-linked variability more reliably than the precise trial-wise response phase. The result bounds the interpretation of the covariance capture: the model explains the population geometry of reafferent covariance, but additional noise, nonlinearities, or twin-to-recorded mismatch limit single-trial prediction.
```

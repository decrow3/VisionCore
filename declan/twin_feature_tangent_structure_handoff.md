# Handoff: Twin Feature-Tangent Structure Analyses

## Working name

**Twin Feature-Tangent Structure (TFTS)**

This is a new twin-only structural analysis branch. It should not be framed as a decoder, discrimination, information, or behavioral-benefit analysis. It asks how retinal translations are transformed into model population response tangents by the canonical shared digital twin.


## Scientific motivation

The recorded data establish that a large component of foveal V1 shared variability during fixation is reafferent covariance driven by measured eye movements. The existing twin analyses are strongest when they are used structurally: the deterministic model can explain how retinal motion through a visual feature-processing system generates low-dimensional, signal-aligned, image-dependent covariance.

The present analysis moves one level upstream from covariance. Instead of starting with:

```text
C_FEM(I) = Cov_e[r_I(e)]
```

we analyze the first-order rate map:

```text
r_I(e)
```

and its local translation tangent:

```text
J_I = [bx_I, by_I] = [∂r_I/∂x, ∂r_I/∂y]
```

where `I` is image content and `e` is retinal displacement.

The conceptual question is:

> Are the image-specific tangent maps generated by a compact shared feature operator?

This is different from asking whether all images share the same signed `bx/by` directions. They probably do not. Each image has different local gradients and features, so the tangents should be content-dependent. The shared structure may instead be the **law** that generates tangent maps from image structure through fixed model features.

---

## Why this is twin-only first

For the canonical shared twin cells, we do not need to estimate each cell's RF, STA, STE, orientation, spatial frequency, or simple/complex status. The model already defines the image-computable mapping:

```text
stimulus movie → model rates
```

Therefore we can directly compute translation tangents by perturbing the retinal image or, where feasible, by differentiating through the model.

This avoids the weakest part of recorded-data identity tests: noisy or incomplete per-cell feature characterization.

Use the twin to answer:

```text
What does a feature-tuning-based translation structure look like when the feature operator is known?
```

Then later, if useful, recorded data can be compared at the level of structural laws rather than unit-by-unit tangent vectors.

---

## Relationship to prior twin prescription

This analysis is consistent with the prior twin covariance prescription, which explicitly restricted the twin to deterministic structural questions and separated those from performance or information claims. That prescription framed the twin as a clean generative model of reafferent covariance rather than a behavioral observer.

The current analysis adds a first-order layer:

```text
first-order tangent map:
    J_I = ∂r_I/∂e

second-order FEM covariance:
    C_FEM(I) = Cov_e[r_I(e)]
```

In a small-cloud linear approximation:

```text
C_FEM(I) ≈ J_I Cov(e) J_Iᵀ
```

This equation is not to be used as a magnitude identity claim. It is a conceptual bridge showing that the covariance is the second-order shadow of the first-order rate map under the eye-position occupancy distribution.

Guardrail:

```text
Do not revive the failed JΣJᵀ magnitude identity branch.
Use the tangent map for structure, compactness, subspace, and prediction analyses.
```

## Core hypotheses

### Hypothesis 1: Tangents are image-specific but not arbitrary

For each image, `bx_I` and `by_I` will differ because each image has different gradients and local features. However, the collection of all tangent maps may occupy a compact population subspace or obey a shared generative law.

### Hypothesis 2: Shared structure lives in the feature operator, not necessarily in a universal signed axis

The strongest naive signed-map hypothesis is:

```text
bx_I ≈ bx_shared
by_I ≈ by_shared
```

This may fail even when a lawful feature-tuning translation code exists.

The better hypothesis is:

```text
tangent map = fixed feature operator applied to image translation structure
```

or informally:

```text
fixed V1 feature filters × image gradients → image-specific tangent maps
```

### Hypothesis 3: The FEM covariance backbone is generated by tangent-map structure plus eye-position occupancy

A large shared cross-image covariance component can exist even when signed tangents are image-dependent, because the tangent maps may share a compact operator or metric structure and because the eye-position occupancy distribution is common.

# Analysis 1: Compute twin translation tangents

## Goal

Compute local first-order response tangents for each image:

```text
bx_I = ∂r_I/∂x
by_I = ∂r_I/∂y
```

for the canonical twin cells.

## Method

For each image or image-history sample `I`, render three or five variants:

```text
centered:     I(e0)
x_plus:       I(e0 + δx)
x_minus:      I(e0 - δx)
y_plus:       I(e0 + δy)
y_minus:      I(e0 - δy)
```

Then compute central finite differences:

```text
bx_I = (r(x_plus) - r(x_minus)) / (2δ)
by_I = (r(y_plus) - r(y_minus)) / (2δ)
```

Use multiple δ values for a sensitivity check:

```text
δ ∈ {0.5, 1.0, 2.0} arcmin
```

or the equivalent in model pixel units. Record the unit convention.

If differentiable rendering is already available, optionally add an autograd version, but finite differences should be the canonical first pass because it matches the conceptual retinal-shift perturbation.

## Important controls

For each image, compute:

```text
||bx||
||by||
cos(bx, by)
rank(J)
singular values of J
R² of local linear tangent approximation over a small validation cloud
```

The validation cloud should sample small retinal offsets around `e0`; compare:

```text
r(offset) - r(center)
```

against:

```text
J · offset
```

This tells us whether the tangent is a reasonable local approximation.

# Analysis 2: Union dimensionality of tangent maps

## Goal

Ask whether all image-specific tangent maps occupy a compact shared subspace.

## Method

Stack all `bx` and `by` vectors:

```text
B = [bx_1, by_1, bx_2, by_2, ..., bx_N, by_N]
```

where each column is `n_units`.

Compute:

```text
eigenspectrum of B Bᵀ
participation ratio
cumulative variance explained by top k
effective rank
```

Report separately for:

```text
bx only
by only
combined bx/by
```

Also compute after per-image normalization:

```text
unit-norm tangents
z-scored tangents across units
raw tangents
```

because raw magnitude may be dominated by image contrast.

## Nulls

Use nulls that preserve some trivial structure:

```text
unit-shuffle within each tangent vector
image-label shuffle, if paired image features are used later
random Gaussian vectors matched to tangent norms
phase-scrambled image tangents, if generated
orientation/gradient shuffled tangents, if generated
```

The most important null for compactness:

```text
random vectors with same number of images, units, and per-column norms
```

# Analysis 3: Train/test shared tangent basis

## Goal

Test whether a basis learned from one set of image tangents captures tangents from held-out images.

This is stronger than measuring compactness on all images at once.

## Method

Split images into train/test folds.

For each fold:

1. Build `B_train` from train images.
2. Compute top-k basis `U_train`.
3. Project held-out tangents onto `U_train`.
4. Compute fraction of held-out tangent variance captured.

Run for:

```text
k_basis ∈ {1, 2, 3, 5, 10, 20, 50}
```

Repeat for:

```text
bx only
by only
combined bx/by
```

Use cross-validation:

```text
5-fold if enough images
leave-one-image-out if image count is small
```

## Nulls

Compare to:

```text
random orthogonal basis of same dimension
basis from unit-shuffled tangents
basis from phase-scrambled / gradient-shuffled images if available
```

## Outputs

Save:

```text
twin_tangent_train_test_basis.csv
twin_tangent_train_test_summary.csv
figures/twin_tangent_train_test_capture.png
```

Fields:

```text
fold
component_set
k_basis
test_variance_capture
random_basis_capture_mean
random_basis_capture_ci_low
random_basis_capture_ci_high
```

```text
If not:
    tangent structure is mostly image-specific at the population-vector level.
```

# Analysis 4: Feature-gradient law using model perturbations

## Goal

Test whether the image-specific tangent maps are lawfully related to image structure.

This is the twin-only replacement for trying to perfectly characterize recorded RFs. In the twin, the feature operator is known implicitly by the model.

## Two implementation tiers

### Tier 4A: Image-gradient summary vs tangent metric

This is the simpler first pass.

For each image, compute image statistics:

```text
RMS contrast
mean gradient magnitude
gradient anisotropy
dominant gradient orientation
Fourier amplitude spectrum slope
orientation energy distribution
SF-band energy
```

Then compare these to the tangent metric:

```text
J_I = [bx_I, by_I]
G_I = J_Iᵀ J_I
```

where:

```text
G_xx = ||bx||²
G_yy = ||by||²
G_xy = bx · by
anisotropy = eigenvalue_ratio(G)
dominant_tangent_angle = leading eigenvector angle of G
```

Test:

```text
Does local/global image gradient anisotropy predict tangent anisotropy?
Does dominant image orientation predict dominant tangent direction?
Does contrast predict tangent magnitude?
```

This does not require decomposing every model feature.

### Tier 4B: Layer-feature tangent decomposition

This is more mechanistic and model-specific.

For each selected model layer:

1. Compute layer activation for centered image.
2. Compute layer tangent under ±x and ±y shifts.
3. Estimate the union compactness and train/test basis at that layer.
4. Propagate or relate layer tangent structure to output-rate tangents.

Candidate layers:

```text
frontend temporal conv output
stem output
resblock1 output
resblock2 output
convGRU hidden state
readout pre-softplus
rate output
```

Questions:

```text
At what layer does tangent structure become compact?
Does compactness increase through the model?
Is the output tangent compactness inherited from readout pooling or earlier feature maps?
```

# Analysis 5: First-order covariance approximation

## Goal

Relate the first-order tangent map back to the full FEM covariance.

## Method

For each image, estimate an eye-position covariance:

```text
Σ_eye = Cov(e)
```

using either:

```text
real fixational eye-position samples
matched occupancy cloud
small isotropic cloud
```

Then compute the first-order approximation:

```text
C_linear(I) = J_I Σ_eye J_Iᵀ
```

Also compute full sampled model covariance:

```text
C_full(I) = Cov_e[r_I(e)]
```

using actual sampled offsets.

Compare **structure only**, not absolute magnitude as a headline.

Metrics:

```text
subspace overlap between C_linear and C_full
top eigenvector alignment
participation ratio comparison
fraction of C_full variance captured by C_linear subspace
correlation of pairwise covariance entries, diagnostic only
```

Do not repeat the failed old branch by claiming precise magnitude identity.

## Outputs

Save:

```text

figures/twin_linear_vs_full_covariance_subspace.png
```


```text

    first-order tangents explain the dominant geometry of FEM covariance.

If subspace alignment is low:
    finite-cloud curvature/history/nonlinearity dominates covariance structure.
```

## Recommended execution order

1. Compute finite-difference twin tangents for a small image set and verify stability across δ.
2. Run tangent union compactness.
3. Run train/test tangent basis capture.
4. Run tangent metric law with simple image-gradient/orientation statistics.
5. Run first-order covariance approximation vs full sampled model covariance.
6. Only if these are interpretable, add layer-feature tangent decomposition.

Do not start with layer decomposition. It is useful but can become a time sink.

## Expected useful outcomes

### Outcome A: Compact and predictive

```text
Tangents are image-specific but live in a compact shared subspace.
Train-image basis captures held-out image tangents.
First-order covariance approximation captures full FEM covariance geometry.
```

Interpretation:

```text
The twin implements a shared feature-tangent operator. FEM covariance is the second-order consequence of translating images through this operator.
```

### Outcome B: Compact but not predictive from simple image statistics

```text
Tangents are compact and generalize across images, but simple gradient/orientation statistics do not predict metric geometry.
```

Interpretation:

```text
Shared structure exists, but it is implemented in deeper nonlinear model features rather than simple image gradients.
```

### Outcome C: High-dimensional tangents but low-dimensional covariance

```text
Tangent maps are high-dimensional, but sampled C_FEM is low-dimensional.
```

Interpretation:

```text
Low-rank FEM covariance is driven mainly by eye-position occupancy and finite-cloud sampling, not by a compact tangent operator.
```

### Outcome D: Mostly image-specific

```text
Tangents do not share a compact basis and do not generalize across images.
```

Interpretation:

```text
The shared covariance backbone likely reflects occupancy/statistical smoothness rather than a shared tangent operator.
```
